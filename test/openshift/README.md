# OpenShift testing

1. Install Dagger CLI (0.20.8)
2. Install SDK via `dagger install github.com/dagger/dang-sdk`
3. Run `dagger fn call check`

## Reviewing results

Run `dagger call check export --path ./report` to get a directory of container image and chart verification reports.
